1. Build the extension:

   ```sh
   npm run build
   ```

2. Open `chrome://extensions` in Chrome and enable **Developer mode**.
3. Click **Load unpacked** and select the `dist/` folder.
4. Click the extension icon, enter your QuickNode Solana RPC URL.
5. Open a Pump.fun profile at `https://pump.fun/profile/<address>`.
6. Click **verify**, select at least **3 callouts** (3–5 recommended), and click **Send**.
